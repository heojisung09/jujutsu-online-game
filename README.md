# 신주쿠 결전 온라인 대전 (초기 구현)

## 포함 파일
- `index.html`: 기존 게임에 온라인 방 생성/입장 UI와 네트워크 클라이언트를 추가한 파일
- `server.js`: WebSocket 방 관리 및 호스트 상태 전달 서버
- `package.json`: 서버 의존성 및 실행 설정

## 로컬 테스트
1. Node.js 18 이상 설치
2. 이 폴더에서 `npm install`
3. `npm start`
4. 브라우저에서 `http://localhost:3000` 열기
5. 한 브라우저에서 방 만들기, 다른 브라우저/기기에서 같은 주소로 코드 입장

두 기기를 테스트할 때는 둘 다 같은 컴퓨터/네트워크 주소 또는 공개 배포 주소를 사용해야 합니다. `localhost`는 각 기기 자신을 가리키므로 다른 기기에서 사용할 수 없습니다.

## 인터넷 배포
Node.js 웹 서비스를 지원하는 호스팅에 이 폴더를 배포하고 시작 명령을 `npm start`로 설정하세요. HTTPS 배포에서는 WebSocket도 WSS로 자동 연결됩니다. 서버의 `/health` 주소로 실행 여부를 확인할 수 있습니다.

## 알려진 제한
이것은 기존 시뮬레이터에 실시간 대전 기반을 추가한 초기 버전입니다. 호스트 권한으로 전투를 계산하고 상대 입력/스킬 입력 및 게임 상태 스냅샷을 전달하도록 구성했습니다. 기존 코드에 포함된 모든 특수 상호작용(예: 특정 캐릭터 전용 선택 UI, 일시정지/재심 흐름)이 온라인에서 완전히 검증된 것은 아니며, 네트워크 지연·끊김 복구·치트 방지·재접속은 구현되지 않았습니다. 실제 공개 전에는 두 기기에서 충분히 테스트해야 합니다.
